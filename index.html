© 2026 米格实验室 · DCC文控原型 P2 · 对齐需求说明书 V1.5.3（阶段水印 / 角色视图 / 合规按级别）

使用者操作流程指南

对齐需求 V1.5.3。先分清文件级别与所属部门；顶栏切换角色后，工作台统计、「我的受控文件」、待办与培训会同步变化。

0文件级别是什么？（原「产品类型」）
一级 · 宏观文件：公司级/宏观制度。网页不可直接改正文；新建、修订、作废都要走审批（部门负责人 → 文控终审）。
二级 · 部门细则：各部门具体作业细则。网页不可直接改正文；新建、修订、作废同样要审批。
三级 · 表单：可在台账「编辑表单」直接改；每次保存自动升主版本并记版本历史（免审批）；新建/作废仍走审批。
组织口径：行政部（文控）+ 市场部 / 技术部 / IT部 / 财务部。对本部门非机密的一/二/三级文件均可直接下载/打印；编制部门与所属部门同口径，便于演示本部门直下。
1哪些要审批？哪些不要？
需要审批：一级/二级的新建、修订、作废；三级的新建入库、作废；外发；非本部门或机密文件的打印/下载二次申请；借阅等（链：部门负责人 → 文控）。
不需要审批：三级表单网页日常改内容；本部门非密一/二/三级的下载/打印；已有权限时的水印预览。
2新建受控文件（一级 / 二级 / 三级首次入库）
①新建申请选文件级别 + 所属部门
→
②部门负责人审电子签名
→
③文控终审确认编号生效
→
④文控勾选分发不自动全员分发
→
⑤签收 / 培训三级可再编辑表单
3改内容怎么走？
一级/二级修订申请变更原因+生效日 → 审批 → 升版
→
旧版失效通知与纸质回收回收完才可关变更单
→
三级表单台账「编辑表单」保存即升版，免审批
4下载 / 打印怎么判断？
①是否机密？有「密」→ 必须二次申请
→
②是否本部门？一/二/三级非密均可直下直打
→
③否则申请可选具体文件后提交
→
④水印输出平铺水印 + 红色阶段水印
顶栏切换部门员工体验本部门直下；文控有全局下载打印权限。打印/下载申请弹窗须选择文件，不再写死演示文件。
5红色阶段水印看什么？
初级文件（新建/审批中）· 审批完成（已生效未分发）· 已分发 · 修订 · 失效（旧版/废止）
借阅 / 外发：从对应列表点预览时左上角显示「借阅」「外发」
机密：正中央斜对角拉长「机密文件」，可与上列角标同时出现
原有姓名·工号·编号·时间平铺水印保留不变；阶段水印字号偏小，避免挡正文。可在「基础配置 → 水印策略」分阶段预览。
6切换角色后看什么？
我的受控文件：只看分发给当前角色的文件（签收状态各自不同）
工作台数字：待审批 / 待签收 / 培训 / 申请中等角标同步变
培训待办：只显示当前人的任务
打印下载申请：文控看全部，其他人只看自己的
近 7 日生效：按所属部门或数据域收窄
7审批与其它主路径
①工作台待办或「待我审批」
↓
②去处理 → 意见 + 电子签名
↓
③通过进下一节点；驳回回草稿
借阅/外发：新建表单 → 选择文件 → 提交审批
作废：必填原因 → 部门 → 文控 → 回收纸质
外来：登记后需审批入库
合规导出：选时间点 + 范围（全库/一级/二级/三级）打包下载
编制人：新建/修订/作废（一二级改正文必经此） 部门负责人：审批签名 文控员：终审、分发、纸质、合规导出 部门员工（行政/市场/技术/IT/财务）：本部门非密一/二/三级可直下直打；看自己的受控份与培训
