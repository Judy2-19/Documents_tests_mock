受控文件全生命周期管理系统（方案 A：嵌入米格现有后台 / 若依）。可点测前端在 **`web/`**（Vite + Vue 3.5 + TS + Vue Router）；正式开发挂现网菜单，后端 **JDK 17 + Spring Boot 3.4 + MyBatis Plus + MySQL + Redis**，表前缀 `dcc_`。

## 2. 建设目标（摘自需求 V1.5.18）

1. 统一受控文件台账，避免多版本并存、过期文件继续使用  
2. 新建 / 修订 / 作废线上审批（电子签名 + 时间戳 + 岗位权限）；**不强制质量批准，文控终审**  
3. 变更通知、新旧版本替换与纸质回收闭环（待回收→实物回收→盖废章）；修订/作废必填变更原因 + 确切生效日  
4. 电子分发签收 + 纸质受控份 / 强制水印打印  
5. 借阅（跨部门临时预览）、外发（令牌+水印包）；外来文件仅文控/负责人登记且必传附件  
6. 文件生效联动岗位培训任务；培训证明可下载（含水印）  
7. 震慑+溯源：下载/打印强制水印（预览可由文控开关）+ **红色阶段状态水印**；机密正中斜对角标  
8. 全文检索 + 编号 / **文件级别**精准筛选  
9. 一键合规导出（范围：全库 / 一级 / 二级 / 三级）  
10. 角色工作台：「我的受控文件 / 待办 / 培训」按角色过滤  

**密级**：仅「内部 / 机密」；机密文件名称后标红色「密」。  
**数据域**：仅「生产域 / 研发域」。  
**组织口径（演示）**：行政部（文控）+ 市场部 / 技术部 / IT部 / 财务部；编制部门与所属部门同口径。  
**文件级别**：一级宏观 / 二级细则 / 三级表单；本部门非密一～三级均可直下/直打。

## 4. 原型菜单与能力（对齐 V1.5.18）

| 分组 | 页面目录 | 原型能力 |
|---|---|---|
| 总览 | `overview/` | 角色统计、待办、近 7 日生效、流程指南 |
| 文件库 | `library/` | 台账筛选/全文、分页 13 条/页、详情、水印预览下载、受控打印 |
| 文件库 | `library/`（我的受控/签收） | **按角色过滤**；签收、预览、下载、打印 |
| 申请与审批 | `approval/` | 申请（新建/修订/作废+真实附件+我的申请）、待我审批 |
| 变更管理 | `change/` | 变更单、变更通知；催办更新未读数 |
| 分发与签收 | `distribution/` | 分发单、纸质受控/打印（筛选+两步回收/盖废章） |
| 借阅与外发 | `borrow/` | 跨部门借阅、外发令牌/水印包、打印/下载二次申请 |
| 培训任务 | `training/` | 我的培训待办、岗位培训矩阵 |
| 外来与复审 | `external/` | 外来登记（文控/负责人+附件）；复审结论 |
| 台账查询 | `report/` | 访问日志、合规导出（按文件级别）；综合查询等复用业务页 |
| 基础配置 | `config/` | 单页「基础配置」，页内选分类/业务领域/所属部门/编号/审批/水印 |

**顶栏**：切换演示角色（文控员 / 各部门负责人 / 各部门员工）。

## 5. 与需求对照（缺口）

| 需求要点 | 原型情况 |
|---|---|
| 现网登录 / 组织 / 角色 / 文件服务 | 未接；Mock 角色切换 |
| 审批真实流转与持久化 | 内存演示；刷新还原 |
| 服务端转 PDF + PDF.js | 水印 HTML 下载，可浏览器另存 PDF |
| 完整版本状态机 / 详情多 Tab | 简化状态 + 版本历史表 |
| 后端 API / MySQL `dcc_` | 无 |

正式开发以需求说明书 **V1.5.18** §2 / §8～§14 / §19（含 §19.8～§19.9）为验收依据。

## 6. 角色与核心对象（速查）

**演示角色**：文控员（行政部）、技术/市场/IT/财务部负责人、技术/市场/IT/财务部员工（无独立行政部负责人）。

**核心对象**：文件主档、版本、申请单、审批、变更、分发、签收、纸质受控份、借阅、外发、外来文件、复审、培训任务、合规导出。
